## [0.1.0] - 2026-08-16

### Added

- Loopback-only xAI OAuth adapter extracted from Hermes Agent.
- OpenAI Codex OAuth adapter with Responses routing and provider-owned headers.
- Composite model-aware routing and merged model discovery.
- Synthetic tests for routing, credential-header isolation, refresh retry, and loopback enforcement.
- CLI, systemd example, architecture, migration, acceptance, security, and contribution documentation.
